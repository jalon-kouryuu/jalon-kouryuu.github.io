Pandas入门简介

基本

简介

  • 说明：python库，用来分析、清洗、处理数据

  • 前提

    • python基础
    • 数学基础：统计学、线性代数

  • 安装： pip install pandas

概念

  • 数据结构

    • series：一维数组，类似表中的一列

    • dataframe：二维数组，类似一张表

    • panel: 三位数组（不常用）

  • 基本操作

    • IO处理：read_csv/to_csv, read_json, …
    • 查看数据
      • 查看：head, tail, info, describe, index, columns, values, corr
      • 切片/索引：loc, iloc, at, ia
      • 筛选：where, mask, isin, ><~
    • 数据清理
      • 变换：T, map, reset_index, astype, to_datetime, to_string
      • 排序：sort_values, sort_index
      • 统计：any, all, count, value_counts, duplicated
      • 补正：dropna, fillna, drop, drop_duplicated
      • 结合：concat, append, join, merge, groupby，split, apply, combine, stack, unstack
      • 时序：date_range, resample, at_time
    • 可视化(利用matplotlib)
