Python介绍&知识点范围

Posted on 2023-10-27 In tech

Python开发者相关入门介绍

1. 概要

1.1 Mindset

  • 兴趣：最好的老师
  • 毅力：枯燥的代码
  • 细心：繁琐的逻辑

1.2 前提

  • 基本的编程思想
    • 面向过程
    • 面向对象
  • 严谨的逻辑思维能力
    • 数学
    • 表达
    • 创造力
  • 较强的自学能力
    • 查阅书籍资料
    • 阅读他人代码
  • 团队协作能力
    • 设计讨论
    • 协同开发
    • 代码审查
  • 一定的语言能力（+英语 以及其他）
    • 语法&命名规范&注释
    • 开发文档编写
    • 方便上网找相关问题的答案

2. 开发环境

2.1 编程环境

  • 语言：Python

    • 版本列表: 目前推荐ver>3.9，如3.9.4

  • 工具库管理包：pip（一般随python一同安装）

  • PY版本控制：Pyenv

  • 项目环境控制：Virtualenv

  • 版本管理：Git

  • 应用打包工具：Pyinstaller、Docker

  • IDE：

    • （推荐）**VSCode**：各类语言通用
    • jupyter notebook / jupyterlab：用于数据分析/PoC
    • 其他：Atom、pycharm等

2.2 其他环境

  • 系统环境（OS）

    • Windows
    • MacOS
    • 其他linux系列：ubuntu、centos等

  • web应用服务器：Microsoft IIS、Nginx、Apache等

  • 部署服务器

    • 本地部署（on-premise）：
      • 优点：高安全性
      • 缺点：前期成本高、需要专业运维人员
    • 云部署（cloud）：Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, Alibaba Cloud
      • 优点：配置灵活、按需收费、售后保障
      • 缺点：学习成本、数据安全性相对本地部署差

3. 基础

3.1 Python介绍

  • 用途
    • 创建web应用
    • 独立软件
    • 数据库操作和文件处理
    • 数据分析
    • 原型和概念验证（PoC）
  • 特点
    • 入门容易（适合非软件/计算机方向的人）
    • 文档资料丰富
    • 用途广泛

3.2 语法&结构

  • 数据结构：基本数据结构

    • 数据类型：数字、字符串、元组、列表、集合、字典、其他

  • 运算

    • 基本运算：+、-、、/、%、*
    • 正则表达式（re）

  • 函数&类

    • 函数的定义、调用 def
    • 类的定义、实例化、继承 class

  • 条件控制

    • 条件语句：if else
    • optional：高版本的case
      • Do case

  • 循环控制

    • for
    • while

  • 错误异常

    • 抛出错误
    • 捕捉异常

3.3 常用处理

  • 模块/库的引用
  • 命令行参数读取、执行（args）
  • 文件的读取保存（json、yaml、txt、csv文件）
  • 数据库连接（CRUD操作）
  • 网络请求（GET、POST等）
  • 绘图（柱状图、折线图、饼状图等）
  • …

3.4 用途以及对应库

  • 内置库：os, sys, datetime,…

  • 第三方库

    • 数据格式：json, yaml
    • 数据处理：numpy, pandas, opencv, pillow
    • 机器学习：sklearn, keras, tensorflow, PyTorch
    • 数据可视化：matplotlib, seaborn
    • 网络爬虫：requests，urlib，beautifulsoup，selenium
    • 后端搭建：cherrypy, flask, django
    • 数据库
      • 关系型数据库：postgreSQL, mysql, sqlserver，…
      • 非关系型数据库：redis, mongodb, …
    • 图形界面：QT
    • 其他

4. 升级

4.1 功能

  • 推导式（列表、字典、集合、元祖）
  • 运算符重载
  • 类的继承&抽象&接口
  • 装饰器（decorator）
  • 并发（异步、协程）
  • 元编程

4.2 最佳实践

  • 设计原则：6大原则

    • 单一职责（SRP）
    • 里氏替换原则（LSP）
    • 接口隔离原则（ISP）
    • 开发-封闭原则（OCP）
    • 依赖倒置原则（DIP）
    • 迪米特法则（LoD）

  • 设计模式：3种类别

    • 创建型：单例、工厂…
    • 结构型：门面、代理…
    • 行为型：观察者、命令者…

  • 其他

    • 接口设计（Restful风格接口）
